# 지침 로딩 점검

코드나 설정을 수정하지 않는 점검이다. 커밋·테스트 실행·작업 위임·모델 변경을 하지 않는다.

현재 세션에 실제로 주입되거나 로드된 정보만 근거로 아래를 짧게 응답한다.

1. 자신의 역할과 현재 작업 경로.
2. 공통 지침과 역할 지침에서 각 하나의 적용 규칙.
3. Paperthin 카탈로그의 `readchk`, `modelchk`, `shower`, `re0` 실제 경로와 각 적용 조건. 경로가 없거나 파일을 읽지 못했다면 그 상태를 명시한다.
4. 자신의 역할에 적용 가능한 Paperthin 스킬 하나를 읽고 확인한 지침 하나. 읽지 않은 내용을 확인한 것처럼 쓰지 않는다.
5. 주입된 실행 정보에서 확인 가능한 런타임·모델·effort. 실행 정보에 없는 값은 확인 불가로 적는다. 자기 응답만으로 실제 사용 모델이 검증되는 것은 아니라는 한계를 적는다.

`modelchk`는 추천만 하며 실행 설정을 바꾸지 않는다. `shower`는 실제로 실행하지 않고, 별도의 도구 없는 `cold-read --artifact FILE` 세션에서 사용하는 규칙만 설명한다. Compound Engineering은 사용하지 않는다.
