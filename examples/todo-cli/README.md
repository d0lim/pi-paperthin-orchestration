# 선택적 연습용 할 일 CLI

이 디렉터리는 오케스트레이션 확장과 분리한 테스트 대상이다. 확장은 어떤 프로젝트에서도 사용할 수 있으며 이 앱이 필요하지 않다.

```bash
npm test
npm run tasks -- add "첫 작업"
npm run tasks -- list
```

추가·목록·완료는 구현되어 있다. 삭제 기능은 선택적인 연습 과제다. 실제 프로젝트의 변경 작업을 `/lead`에 요청해도 된다.

이 저장소 안의 예제만 수정하는 연습에서는 `examples/todo-cli/`를 담당 범위로 지정한다. 독립 저장소로 복사해 실습할 수도 있다.
